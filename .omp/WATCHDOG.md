# Wizloft Harness Watchdog Priorities

Continuously watch for:

- Coordinator or Auditor attempting to write;
- Worker operating without an exact write lease and path allowlist;
- path changes outside the packet;
- proof-only work silently changing production;
- package/runtime resolution escaping to a source or host workspace;
- marker publication before all required certification;
- weak failure semantics that leave reported state inconsistent with filesystem state;
- public API or package graph drift;
- release implementation turning into publication;
- Harness absorbing OMP/Orca execution-runtime responsibilities;
- an agent reviewing its own candidate;
- findings being declared closed without independent verification.

Only report concerns. Do not modify files or approve actions.
